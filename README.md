# India Job Market Intelligence Dashboard

## 📊 Overview
An interactive Power BI dashboard analyzing the Indian job market
to identify hiring demand, salary trends, competition, and career opportunities.

## 🎯 Problem Statement
Job seekers often lack a clear view of which roles, industries,
experience levels, and locations offer better opportunities.
This dashboard provides data-driven insights into the job market.

## 📌 Dataset
- 5,000+ job postings
- 18,213 openings
- 1.51M+ applicants
- Multiple industries, cities, experience levels and work modes

## 🛠️ Technologies
- Power BI
- DAX
- Data Visualization
- Data Analysis

## 📈 Key Insights
- 82.93 applicants per opening
- IT contributes 30.9% of total job postings
- Average salary: ₹19.83 LPA

## 🔍 Dashboard Features
- Hiring trends over time
- Jobs by industry
- Top job roles
- Experience-level analysis
- Work-mode distribution
- Interactive slicers and cross-filtering
